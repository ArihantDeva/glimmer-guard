# Contributing

**This repository is not maintained and does not accept contributions.**

It exists to publish a hackathon submission and its measurements so the
numbers can be reproduced. Pull requests are not reviewed. Issues are kept
disabled. There is no roadmap, no support, and no commitment to respond.

You are welcome to fork it under the MIT licence and take it wherever you
want. If you need a maintained tool-call guard, use one that has a maintainer.
